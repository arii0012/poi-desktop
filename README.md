# PoiDesktop

Красивые фигуры + код-варианты + установка обоев на Windows (работает **даже если Windows не активирована**).

Написано на **Rust** + **egui** — быстро, плавная анимация 60 FPS, современный интерфейс.

## Возможности

- 32 фигуры (планета, ракета, CS2, котик, НЛО, писюн, сиська и др.)
- **Код-фигуры меняются** в зависимости от выбранной фигуры  
  (выбрал «Планета» → появляются Земля / Марс / Сатурн / Юпитер / Чёрная дыра)
- Живой превью с вращением, свечением, радугой
- Статичный режим
- Установка обоев через WinAPI (без активации)
- Возврат предыдущих обоев одним кликом
- Сохранение PNG в высоком разрешении
- Тёмная тема

## Как собрать

### Требования
- [Rust](https://rustup.rs/) (1.75+)
- Windows 10/11 (для установки обоев)

```bash
git clone https://github.com/YOUR_USER/poi-desktop.git
cd poi-desktop
cargo build --release
```

Готовый файл: `target/release/poi-desktop.exe`

### Запуск без установки Rust
Скачай готовый `.exe` из **Releases** на GitHub (собирается автоматически через Actions).

## Горячие действия в программе

| Действие                    | Что делает                          |
|----------------------------|-------------------------------------|
| Выбор фигуры               | Меняет список код-фигур             |
| Установить обои            | Рендерит 1920×1080 и ставит на рабочий стол |
| Вернуть старые обои        | Восстанавливает предыдущие          |
| Сохранить превью           | PNG в `%LOCALAPPDATA%\PoiDesktop\wallpapers` |

## Структура

```
poi-desktop/
├── Cargo.toml
├── src/
│   ├── main.rs          # UI + анимация + логика
│   ├── shapes.rs        # фигуры + контекстные код-варианты
│   └── wallpaper.rs     # WinAPI set/restore
├── .github/workflows/build.yml
└── README.md
```

## Сборка на GitHub Actions

При пуше в `main` или создании тега автоматически собирается `poi-desktop.exe` и публикуется в Releases.
