# PoiDesktop 2.0

Крутые 3D-фигуры, код-варианты, фото→фигура, виджеты, сцены и обои для Windows.

## Сборка

1. Rust: https://rustup.rs  
2. (если нужно) Build Tools: https://visualstudio.microsoft.com/visual-cpp-build-tools/  
   → Desktop development with C++
3. В папке проекта:
```
cargo build --release
.\target\release\poi-desktop.exe
```
Или двойной клик по `build.bat`.

## Новое в 2.0

- 3D-глубина и перспектива
- 6 режимов анимации (вращение, пульс, орбита, волна, прыжок, глитч)
- Фото → фигура (загрузка картинки)
- Виджеты: часы, дата, свой текст
- Сцены: звёзды, градиент
- Пресеты одним кликом
- Шлейф, зеркало, автосмена фигур
- Свет, FOV, размер точек
- Экспорт PNG и 4K
- Код-фигуры меняются с выбранной фигурой
- Установка/возврат обоев (без активации Windows)
