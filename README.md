# PoiDesktop

Красивые фигуры + код-варианты (меняются при выборе фигуры) + установка обоев на Windows.

Работает **даже если Windows не активирована**.

## Быстрый старт (Windows)

1. Установи Rust: https://rustup.rs (нажми Enter везде)
2. Открой **PowerShell** или **cmd** в папке проекта:
```
cargo build --release
```
3. Запуск:
```
target\release\poi-desktop.exe
```

## Если ошибка компиляции

```
rustup update
cargo clean
cargo build --release
```

Нужен **Windows** (для установки обоев). На Linux/macOS программа откроется, но кнопка «Установить обои» покажет ошибку.

## GitHub

Залей эту папку на GitHub → Actions сам соберёт `.exe` (workflow уже лежит в `.github/workflows/build.yml`).

## Что умеет

- 32 фигуры
- Код-фигуры **меняются** под выбранную фигуру (Планета → Земля/Марс/Сатурн/…)
- Живой превью
- Статичный режим
- Установка / возврат обоев
- Сохранение PNG
