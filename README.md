# PoiDesktop 5.0

Живые обои в стиле телефонного PoiPaper / CodeWall.

## Запуск (Windows)

1. Установи Rust: https://rustup.rs
2. В папке проекта:
```
cargo build --release
.\target\release\poi-desktop.exe
```

Или `build.bat`.

## Возможности

- Фигуры + код-варианты
- Пресеты (Сатурн, Сердце, Matrix…)
- Сцены фона, свечение, анимации
- Виджеты часы/дата
- Установка / возврат обоев Windows
